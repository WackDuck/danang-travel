# Website Khám phá Đà Nẵng

Website tĩnh giới thiệu các điểm đến, ẩm thực và thông tin du lịch cơ bản về Đà Nẵng. Đây là bài tập thực hành HTML5 và CSS3, có giao diện đáp ứng cho máy tính, máy tính bảng và điện thoại.

## Các trang

- `index.html`: Trang chủ.
- `about.html`: Giới thiệu về Đà Nẵng.
- `destinations.html`: Những điểm đến nổi bật.
- `food.html`: Ẩm thực Đà Nẵng.
- `gallery.html`: Thư viện ảnh.
- `itinerary.html`: Lịch trình tham khảo 3 ngày 2 đêm.
- `tips.html`: Cẩm nang chuẩn bị chuyến đi.
- `contact.html`: Thông tin và biểu mẫu liên hệ minh họa.
